Política de Privacidad — Consultar IMEI

Última actualización: 26/09/2025

Esta aplicación ("Consultar IMEI", "la App") permite a los usuarios verificar el estado de un IMEI (robo/hurto, reporte, bloqueo) contra bases de datos públicas/oficiales de Colombia. Esta política explica qué información se recopila y cómo se usa.

1. Información que recopilamos

IMEI consultado: el número IMEI que el usuario ingresa manualmente o escanea se envía a nuestro servidor para realizar la consulta. No almacenamos un historial asociado a tu identidad personal.

Cámara: se usa exclusivamente para escanear el código de barras/IMEI en pantalla. No se capturan ni almacenan fotos o videos.

Datos de publicidad: usamos Google AdMob para mostrar anuncios. AdMob puede recopilar identificadores de dispositivo y datos de uso según su propia política. Consulta la Política de Privacidad de Google.

2. Uso de la información

  • Procesar la consulta del IMEI contra la base de datos correspondiente.
  • Mostrar anuncios relevantes a través de AdMob.
  • Mejorar el rendimiento y estabilidad de la App.

3. Compartición de datos

No vendemos ni compartimos información personal identificable con terceros, salvo lo necesario para el funcionamiento de servicios de publicidad (Google AdMob) conforme a su propia política.

4. Menores de edad

Esta App no está dirigida a menores de 13 años y no solicitamos intencionalmente información de menores.

5. Seguridad

Implementamos validaciones en el cliente (formato de IMEI, límites de consultas por minuto) y comunicación cifrada (HTTPS) para proteger la integridad de las consultas.

6. Tus derechos

Puedes contactarnos para solicitar información sobre el tratamiento de tus datos o su eliminación, cuando aplique, a través del correo indicado abajo.

7. Cambios a esta política

Podemos actualizar esta política ocasionalmente. Los cambios se reflejarán en esta misma página con la fecha de actualización correspondiente.
